what it is

Each job gets its own agent; each agent is just a folder with durable, scoped context and a Slack channel. Timers push digests while you sleep and replying in a channel talks to that agent. No platform, No database, No dashboard

what's next

context optimization
Memory today is deliberate markdown files: durable, but flat. Next up is smarter curation of what each agent carries into a run. Pruning, recency weighting, and retrieval instead of read-everything.
fleet memory backups
The notes are the product; they should survive the box. Nightly snapshots of every agent's memory, off-machine.
agents that verify
The coding agent runs a repo's own tests before it opens the PR. Proof, not plausibility.

The how and the why (the invariants, the memory strategy, the once-per-box setup) live where they belong: architecture.md on GitHub.
